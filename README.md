📱 DuidTracker

DuidTracker adalah aplikasi pencatat keuangan pribadi berbasis Android yang membantu pengguna mencatat pemasukan, pengeluaran, serta memantau kondisi keuangan secara praktis dan mudah digunakan.

✅ Fitur Utama
📥 Mencatat pemasukan
📤 Mencatat pengeluaran
📊 Melihat ringkasan keuangan
🧾 Riwayat transaksi
🎨 UI sederhana, modern, dan mudah dipahami
💾 Data tersimpan secara lokal di perangkat
🏗️ Teknologi yang Digunakan
Kotlin
Android Studio
Gradle
(Tambahkan Jetpack / Room / MVVM jika kamu pakai)
📂 Struktur Project
├── app/
│   ├── java/
│   ├── res/
├── build.gradle.kts
├── settings.gradle.kts
├── gradle.properties
└── README.md
🚀 Cara Install & Menjalankan
Clone repository:
git clone https://github.com/RamadhaniMulyaL/DuidTracker.git
Buka project di Android Studio
Tunggu proses Gradle Sync
Jalankan aplikasi pada emulator atau device Android
